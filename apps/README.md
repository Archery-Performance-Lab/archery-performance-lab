# Applications

## Purpose

The `apps` workspace contains all executable applications that compose the Archery Performance Lab ecosystem.

Applications are responsible for exposing user-facing services while relying on reusable packages contained in the `packages` workspace.

---

## Applications

| Application | Description |
|-------------|-------------|
| api | Backend services |
| web | Frontend application |

---

## Design Principles

- Thin applications
- Business logic lives inside packages
- Domain Driven Design
- Dependency Injection
- Clean Architecture
